# Dead Zone: Survival

Top-down zombie survival shooter — single-file HTML/Canvas game. **v2** is live: waves, runners and brutes, score + best score, health/rapid-fire drops, dash, sound effects, and phone auto-aim.

Play on GitHub Pages or on Vercel: https://dead-zone-survival-flax.vercel.app

Controls: WASD/arrows move, mouse aim/fire, Shift/Space dash, P pause, M mute, R restart after game over. On phone: on-screen pad + FIRE button (auto-aim assist).
